# 数据字典

- run_id：规则版本与输入 SHA-256 前 12 位组成的稳定批次标识。
- line_no：从 1 开始的物理来源行号，不因隔离或排序改变。
- business_key：本项目声明的业务唯一键，始终按字符串存储。
- reason_code：隔离原因的稳定英文编码。
- accepted：进入业务计算的记录数。
- quarantined：保留证据但不参与业务计算的记录数。
- 数值：金额、税额、用量和权重使用 Decimal；对外序列化为字符串。
- 时间：存储为带偏移的 ISO 8601，分桶使用半开区间。
- 空值：缺失键、空串和业务哨兵分别记录。
- 幂等：完整输入字节与规则版本相同则复用 run_id，不新增结果。
- catalog_id：目录（登记单元）标识。合并后为扫描件当前归属。
- original_catalog_id：扫描件首次登记的目录，合并与撤回都不改写。
- original_key / original_business_key：首次登记时的文件键与业务键，供旧验收凭据核验。
- catalog_version：目录版本，合并、撤回、登记、裁决各自递增；调用方携带的旧版本会被拒绝。
- merge_id：一次合并票据；其迁移账本是断点续做与撤回的唯一依据。
- mapping_basis：合并映射依据，含请求方提供的内容与自动采集的目录事实。
- 扫描状态：ACTIVE 计入页序；DUPLICATE 同页同摘要不计页；CONFLICT 同页不同扫描挂起待裁决；SUPERSEDED 裁决落选保留为证据。
